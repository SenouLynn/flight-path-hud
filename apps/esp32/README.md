# ESP32 HUD firmware

This is the future on-device application. Its `hud/` C++ library must remain independent of
Arduino, a display driver, and networking so that the exact same code can run on a host/development machine.

## Validate locally first

No ESP32, PlatformIO, or graphics library is required for the first validation loop:

```bash
cd apps/esp32
make test  # compile and run resolver + scene tests with the system C++ compiler
make run   # write build/hud-preview.svg from the same scene composition code
```

Open `build/hud-preview.svg` in any browser or image viewer. It is a deterministic rendering of
the initial primary-flight-display scene, generated by the host executable rather than the web
app.

## Build for an ESP32

The initial target is PlatformIO's generic `esp32dev` board. Install PlatformIO, then:

```bash
cd apps/esp32
pio run
pio run --target upload
pio device monitor
```

The root [setup guide](../../README.md#esp32-firmware) covers the boardless host prerequisites,
the recommended VS Code PlatformIO extension, and the standalone CLI installer. PlatformIO's
first build downloads the ESP32 toolchain automatically.

`src/main.cpp` currently proves the firmware entry point and resolver build through serial
output. Once the display controller is selected, add a `HudDrawTarget` adapter for its line/text
API; the scene geometry itself remains in `lib/hud/src/scene.cpp` and can already be checked on
the host.
