# Web validation harness

The original Vite + React validation app lives here unchanged. It remains the quickest
place to iterate on telemetry fixtures, HUD geometry, and replay tables.

From this directory:

```bash
npm install
npm run dev
npm test
npm run build
```

From the repository root, use `npm run dev:web`, `npm run test:web`, and the matching
`build:web` / `lint:web` commands.
